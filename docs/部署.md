# 部署與安裝步驟

給我們自己（乙方）部署與到場安裝用。帳號擁有者：Supabase、Vercel 用乙方帳號（主機費含在維護費）；Google AI Studio（Gemini）登記在甲方名下、甲方付費，再邀請我們加入成員（合約第十一條第 3 項）。

## 1. Supabase（機房：日本 Tokyo）

1. 建立專案時 Security 三個勾選（CLAUDE.md「Supabase 專案設定與資料庫改動規則」）：
   - Enable Data API ✅
   - Automatically expose new tables ❌
   - Enable automatic RLS ✅
2. 連結與套用資料庫（乙方電腦，CLI 用 `supabase@2.119.0`）：
   ```
   npx supabase@2.119.0 login                                  # 開瀏覽器授權（VS Code 要在 Terminal 裡跑，不能在對話框）
   npx supabase@2.119.0 link --project-ref <ref>               # 不用資料庫密碼
   npx supabase@2.119.0 db push                                # 套用 supabase/migrations/ 全部檔案
   ```
   不要在後台手動改表結構。⚠️ 你的帳號底下還有多租戶系統與永進米行的正式專案，link 前確認 ref 是本專案的。
3. Edge Function secrets：照 `docs/金鑰設定.md` 填好 `supabase/.env.secrets` 後
   `npx supabase@2.119.0 secrets set --env-file supabase/.env.secrets`。
   需要：`GEMINI_API_KEY`、`CRON_SECRET`、`VAPID_PUBLIC_KEY`、`VAPID_PRIVATE_KEY`、`VAPID_SUBJECT`；選填 `AI_CONCURRENCY`（即時模式同時辨識頁數，預設 8）。
4. 部署函式（不用 Docker）：`npx supabase@2.119.0 functions deploy process-queue device-api maintenance --use-api`
   （`supabase/config.toml` 已設定這三個不用 Supabase JWT，各自用排程密鑰／裝置金鑰驗證）
5. 排程設定（取代手動建 vault secret）：
   ```
   curl -X POST https://<ref>.supabase.co/functions/v1/maintenance -H "x-cron-secret: <CRON_SECRET>" -d '{"setup":true}'
   ```
   回應 `"vault": 2` 且 `jobs` 有 process-queue、maintenance 就對了；之後把 `setup` 換成 `status` 可以看最近幾次排程呼叫的結果。
6. Authentication → URL Configuration：Site URL 填系統網址；Redirect URLs 加 `https://<系統網址>/auth/callback`。
7. 確認 Database → Backups 有每日備份（附件一共通規格「備份」）。

## 2. Vercel（網站）

1. 匯入 GitHub repo，Root Directory 設 `web`（npm workspace，Vercel 會在 repo 根目錄安裝）。
2. 環境變數：
   - `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   - `SUPABASE_SECRET_KEY`（只給伺服器端，帳號管理與建立裝置金鑰用；絕對不能加 `NEXT_PUBLIC_`）
   - `NEXT_PUBLIC_VAPID_PUBLIC_KEY`（手機推播公鑰）
3. 綁甲方網域（HTTPS）。

## 3. 建立第一個老闆帳號

```
curl -X POST https://<ref>.supabase.co/functions/v1/maintenance -H "x-cron-secret: <CRON_SECRET>" -H "Content-Type: application/json" \
  -d '{"create_owner":{"email":"老闆 Email","name":"老闆姓名"}}'
```
只有在還沒有老闆帳號時能用；密碼隨機產生、不回傳。**要先做完第 1 節第 6 步（URL Configuration）**，老闆再到登入頁輸入 Email →「忘記密碼」→ 收信設定自己的密碼。
（`scripts/create_owner.ts` 是備用做法，需要 Secret key。）
之後的帳號（會計、複核人員）由老闆在「系統設定 → 帳號與權限」建立。再匯入客戶主檔（系統設定 → 客戶主檔 → 匯入 Excel）。

## 4. 常駐電腦（到場安裝）

1. 取得 `uploader.exe`：改到 `uploader/` push 後，GitHub Actions（`.github/workflows/uploader.yml`）會在 Windows 主機跑測試再打包，到 GitHub → Actions → uploader-windows 下載；或 `gh run download <run id> -n uploader-windows`。（備用：Windows 上執行 `uploader\build.bat`。）
   exe 沒有數位簽章：第一次執行 SmartScreen 會擋，按「其他資訊 → 仍要執行」；防毒軟體誤擋就加到例外。
2. **程式資料夾用英文路徑**：C 槽新增 `C:\UCodeUploader`，放 `uploader.exe`、`install_autostart.bat`、`config.json` 三個檔。
   不要放桌面或使用者資料夾（例 `C:\Users\王小明\桌面\…` 有中文）：`.bat` 在命令列執行，路徑有中文可能變亂碼，開機自動執行會找不到程式。
   掃描資料夾、外接硬碟資料夾用中文沒關係（上傳程式自己讀寫，Windows 測試已用中文資料夾跑過）。
3. 系統設定 → 「新增上傳金鑰」「新增備份金鑰」，複製 `config.example.json` 改名 `config.json`，填入兩把金鑰、`api_url`、`web_url` 與資料夾路徑。
4. **先看掃描機現在怎麼存檔**（業主已經在用，觸控螢幕看現有預設的目的地；或在電腦找平常掃描檔出現的資料夾），能沿用就沿用：
   - **不要直接監看業主現有的掃描資料夾**：上傳程式會把資料夾裡**所有** PDF／圖檔上傳辨識（合約、進貨單也會被送 AI、花錢、多出其他單據紀錄），上傳後**從原處移走**到「已上傳」，第一次啟動還會把累積的舊檔一次全部上傳。一律另開專用資料夾，只有按「收款單據」預設掃的才進去。上傳程式只看 `watch_dir` 那一層，不讀子資料夾、也不讀上一層。
   - **A. 現在已經掃到這台電腦的網路資料夾（SMB）**：共用與帳號密碼都已經設好，抄下現有的路徑與帳號。在那個共用資料夾底下新增子資料夾 `收款單據`（例 `D:\Scan\收款單據`），`watch_dir` 填它、`uploaded_dir` 填它底下的 `已上傳`；第 5 步的目的地路徑用現有路徑加 `\收款單據`、帳號密碼照抄。跳過下面 C 的建資料夾與帳號。
   - **B. 現在用電腦軟體（Epson ScanSmart，USB／WiFi 接電腦）**：可以在 ScanSmart 把存檔資料夾指到專用資料夾，但電腦要開著軟體、會計要在電腦操作；能的話改走 C（掃描機直接存網路資料夾，會計只按掃描機）。
   - **C. 沒有現成的網路資料夾（或存 Email／雲端）**：自己建——
     - 建 `D:\掃描收款`（中文沒關係，同時填進 `config.json` 的 `watch_dir`）→ 右鍵 → 內容 → 共用 → 進階共用 → 勾「共用此資料夾」，**共用名稱用英文 `scan`**（掃描機輸入路徑不一定支援中文）。
     - 建掃描專用的 Windows 本機帳號（不要用業主自己登入的帳號：Microsoft 帳號掃描機常連不上、開機 PIN 不是密碼、業主改密碼掃描就會失敗）：開始搜尋 `cmd` → 右鍵「以系統管理員身分執行」→ `net user scanner 密碼 /add`。密碼記在交接資料。Windows 11 不允許免密碼帳號存取共用。
     - 給這個帳號權限，**兩邊都要給**：進階共用 →「權限」→ 新增 `scanner` → 勾「變更」；內容 →「安全性」→ 編輯 → 新增 `scanner` → 勾「修改」。
   - 查電腦名稱（設定 → 系統 → 關於）；改用 IP 的話要在路由器固定 IP，否則 IP 變了就存不進去。
   - 確認磁碟代號：`Windows 鍵 + E` →「本機」，括號裡就是代號。有 D 槽（硬碟，不是 DVD 光碟機）才用 `D:\掃描收款`；沒有或 D 是光碟機就改 `C:\掃描收款`（`watch_dir`、`uploaded_dir` 一起改）。
   - 外接硬碟**固定代號 `Y:`**：Windows 會因為插隨身碟、換 USB 孔改掉外接硬碟的代號，上傳程式會以為硬碟沒接、一直通知。開始按右鍵 →「磁碟管理」→ 外接硬碟按右鍵 →「變更磁碟機代號及路徑」→ 變更 → 選 `Y` → 確定；`hdd_dir` 改成 `Y:\收款單據備份`。不確定哪個是外接硬碟就拔掉再插，看哪個消失又出現。
   - `config.json` 的路徑反斜線要打兩個（`"Y:\\收款單據備份"`），用記事本編輯、存成 UTF-8、檔名不要變成 `config.json.txt`。
5. ES-580W 建立預設「收款單據」（觸控螢幕，或電腦瀏覽器開掃描機 IP 進 Web Config，打字較方便）：
   - 先新增目的地：網路資料夾（SMB），路徑 `\\電腦名稱\scan`（A 的情況是現有路徑加 `\收款單據`），使用者名稱 `scanner`（連不上改 `電腦名稱\scanner`）、密碼。
   - 再建預設「收款單據」：目的地選它，**彩色、200 dpi、PDF**（不要選黑白，手寫藍筆紅筆會不見）；**單面**（2026-10-29 業主決定背面不掃）。
   - 選單名稱以實機為準（依規格寫，未在實機確認）；找不到就查說明書「掃描至網路資料夾」「Scan to Network Folder」。
   - 測試：按「收款單據」掃一張 → `watch_dir` 資料夾出現 PDF → exe 上傳後移到「已上傳」。
6. 在 `C:\UCodeUploader` 裡執行 `install_autostart.bat` 設定開機自動執行（視窗顯示「已設定」再按任意鍵關閉），再執行 `uploader.exe`；工作列出現綠色圓點。
   - 設定檔有錯（檔名變 `.txt`、反斜線只打一個、金鑰沒貼）會跳視窗說明哪裡錯；已經在執行時再點一次會提示「已經在執行了」（同一台只能開一個）。圓點紅色：滑鼠移上去看原因（例「找不到掃描資料夾」「偵測不到外接硬碟」）。
   - **要在 `C:\UCodeUploader` 裡執行，不要在隨身碟裡直接點**（`install_autostart.bat` 會記下自己所在的資料夾當開機執行位置）。
8. **之後更新上傳程式不用到場**（1.3.0 起）：改 `uploader/` 並把 `VERSION` 加大 → push → GitHub Actions 測試、打包、Windows 自動更新實測都通過後，執行 `./scripts/publish_uploader.sh` 把 exe 放上雲端；常駐電腦 6 小時內自己下載、核對 sha256、換掉 exe 並重新啟動。處理總覽的上傳程式卡片會顯示版本。1.2.0 以前的版本沒有自動更新，要手動換一次（右鍵圓點「結束」→ 覆蓋 `C:\UCodeUploader\uploader.exe` → 點兩下）。
   - `config.json` 的 `keep_local_days`（預設 7）：C 槽「已上傳」只留最近幾天，更早的**確認外接硬碟有同樣大小那份才刪**，外接硬碟還沒補到的一律不刪；0＝不刪。
7. 驗收：掃一疊單據 → 5 分鐘內出現在「掃描與辨識」；「處理總覽」看得到上傳程式最近回報時間與外接硬碟狀態。

## 5. 手機通知

老闆（與會計）的手機：用 Safari／Chrome 開系統網址 → **加入主畫面**（iPhone 必須，iOS 16.4 以上）→ 從主畫面圖示開啟、登入 → 左側（手機在上方）按「開啟手機通知」→ 允許。
之後異常（AI 額度不足、上傳程式沒回報、外接硬碟沒接）與每批辨識完成都會跳通知；異常同時顯示在系統畫面上方。
